# Système Cartésien GUI

Interactive Cartesian System control interface built with React 18 and React Router v6.

## Features

- **Main Menu** — Select from three operating modes
- **Mode Manuel** (Green) — Direct X/Y/Z coordinate input with drawing canvas
- **Mode Import** (Yellow) — Upload G-code or SVG files with progress tracking
- **Formes Prédefinies** (Blue) — Animated shape preview (Carré, Cercle, Spirale)
- Real-time coordinate display on every screen
- Speed control sliders
- Responsive layout

## Getting Started

```bash
npm install
npm start
```

The app launches at `http://localhost:3000`.

## Build

```bash
npm run build
```

## Tech Stack

- React 18.2
- React Router v6
- Vanilla CSS (no CSS-in-JS)
